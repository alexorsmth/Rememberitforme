Simple Idea organizer/documentor that can currently save dates, label idea's based on how much you care about it, and
saves it all within a Supabase Database. 

Currently can do:
- save dates by interacting with a calendar [Implementing FullCalendar.io]
- Take user's ideas
- Allowing users to label ideas based off how they feel about them
- show previously saved ideas on a table

Plan to implement:
- Custom label's (user can choose to make a label object and customize it with their own colours and text (up to a limit)
- Discord/google extension integration [potentially a bot that tries to remind you of ideas that you made so you won't forget]
- more stylization (Currently using alot of default components, would like to add more silly/personal things)

Super far off things:
- Mobile integration
- website animations
- Public access to the app
